# Lectern Speaking Gym

A ten-minute daily speaking gym for professional spoken English: timed professional, conversation and debate drills, filler and register tracking, and a bank of target vocabulary.

Open `index.html`, or visit the GitHub Pages site for this repository. On a phone, add it to the home screen from the browser's Share menu.

- Speak with the keyboard's microphone key; the app analyses the transcript.
- Progress is stored in the browser on the device you use.
- Coach feedback: tap "Copy for Claude" after a drill and paste into a Claude chat.
